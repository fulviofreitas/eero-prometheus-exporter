1,626 of the 1,792 findings were `High` severity, but 1,591 of the total
(89%) were concentrated in patterns that are false positives for this
project's own conventions:

- **`assert` in `tests/**`** (Bandit `B101`, Prospector's bundled Bandit
  pass, Opengrep's `assert_rule-assert-used`) -- pytest's idiomatic
  assertion style, documented in
  `claude/rules/testing.md` and used throughout the 943-test suite. Not a
  production code path; `assert` is never compiled out here because it
  never ships.
- **`W0621` redefined-outer-name in `tests/**`** (Pylint) -- pytest fixture
  functions intentionally shadow their own name when injected as a test
  argument; this is the standard fixture pattern, not a bug.
- **Prospector's bundled pyright pass over `tests/**`** -- this repo's own
  type-checking is scoped to `src/` only (`uv run mypy src/`, see the
  top-level `CLAUDE.md` Quick Commands); test files were never held to that
  bar, so Codacy shouldn't hold them to a stricter one.
- **`MD024` in `CHANGELOG.md`** -- generated by
  `@semantic-release/changelog`; it legitimately repeats section headings
  ("Bug Fixes", "Features", ...) once per release.

None of these are disabled repo-wide: `src/`, `scripts/`, `.github/` and
every other path keep full coverage from all four affected tools
(Bandit, Prospector, Opengrep, Pylint). Only `tests/**`'s tool-specific
false positives are scoped out, and only for those four tools -- Lizard,
ESLint, and Hadolint are untouched everywhere.

No pattern-level (rule) suppression was configured -- Codacy's YAML config
only supports path-level exclusion (`exclude_paths`/`include_paths`,
globally and per-engine); disabling a specific check like `B101` outright
requires the repo's coding standard in the Codacy UI/API, which is out of
scope here. The remaining 7 `Bandit_B101` / 7 `Semgrep_..._assert-used`
hits are in non-test files (`src/eero_exporter/server.py`,
`src/eero_exporter/cli.py`, `scripts/gen_dashboard.py`) and were
deliberately left visible for a maintainer to triage individually.
